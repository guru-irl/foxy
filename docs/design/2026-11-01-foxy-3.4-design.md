# Foxy 3.4.0: agent remove and delete

This extends the agent bridge in `2026-10-04-foxy-3.2-design.md`.

## Commands

`foxy remove <group> <url>... [--close]` matches 1 to 50 HTTP or HTTPS URLs,
ignoring fragments. It removes every match from the named group. Missing URLs
are returned in `missing`. It refuses requests with no matches or requests
that would empty the group. In an open group, it ungroups tabs by default and
closes them with `--close`. Firefox may move ungrouped tabs to a group edge to
keep the remaining group contiguous. In a saved closed group, it removes
bookmarks and `--close` has no effect. Normal sync removes bookmarks for tabs
that leave an open group.

`foxy delete <group> [--close-tabs]` deletes a saved closed group through the
board's delete-saved operation. It refuses to delete an open group without
`--close-tabs`. With that flag, it closes the group's tabs, waits for sync to
process their departure, then deletes the saved folder. The reply contains the
group title, colour and tab titles and URLs so the group can be recreated.
The pinned folder is never a group deletion target.

Both commands use the existing case-insensitive, trimmed group lookup. They
prefer an open group in the last focused normal window to a saved group.
Neither command closes an active tab. An open group on another synced device
may reappear there after deletion.

## Agent safety

Remove or delete only groups or URLs the user requested. Prefer ungrouping to
closing tabs and report deleted URLs. The commands require Foxy 3.4.0; older
versions return an update instruction. Existing bridge commands still require
Foxy 3.2.0 or newer.
