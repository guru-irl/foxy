Foxy collects no data. It has no analytics, advertising, or Foxy account.

Weather requests go to Open-Meteo and BigDataCloud only after you select **Allow weather**. Coordinates are rounded to two decimals before requests. These services receive your IP address and the location needed for the request. Searching for a city does not require geolocation permission. Weather does not use cookies or an API key.

Firefox's own bookmarks and storage sync carry saved groups, pins, settings, and board layouts between your devices. Foxy does not operate a sync server. Location and row density stay on your device. Revoking location data consent removes the cached forecast and place name.

The optional open-source native helper runs locally. It connects Foxy to a local agent CLI and provides memory measurements. It does not send data to a Foxy service. You do not need the helper to use the board.
