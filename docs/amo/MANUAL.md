# Check the AMO submission in Developer Hub

The API syncs the listing, privacy policy, and screenshots. Each version receives the MIT licence, reviewer notes, and source archive. No Developer Hub-only field is required by this listing.

Before the first listed release, complete these checks in [Developer Hub](https://addons.mozilla.org/developers/addons/):

1. Open Foxy, then **Edit Product Page**. Confirm the name is **Foxy Board**, the Firefox categories are **Tabs** and **Bookmarks**, and both screenshots appear.
2. Under **Support Information**, confirm **Support Website** is `https://github.com/guru-irl/foxy/issues`.
3. Open **Manage Status & Versions**. Confirm the distribution includes **On this site** for the first listed version. If AMO requires a distribution change before accepting a listed upload, complete it here before retrying.
4. Open the submitted version. Confirm the source archive, MIT licence, and reviewer notes are attached. Resolve any validation or reviewer questions here. Never resubmit the same accepted version number.
5. Preview the product page and privacy policy. Confirm the Markdown and links render correctly before the page goes public.

After approval, run the **Publish approved AMO releases** workflow for the tag, or let its daily run publish the draft. Do not upload a second copy of the version.
