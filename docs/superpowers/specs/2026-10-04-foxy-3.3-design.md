# Foxy 3.3.0: S cells, pinned icons, memory tile, rail gear, weather tile

Date: 2026-10-04. Builds on `2026-10-03-foxy-grid-design.md` and
`2026-10-04-foxy-3.2-design.md` (both still apply where this spec does not
change them).

## 1. Cell size

- Presets M, L and XL are removed. Cell size is **S (48 px, default)** or
  **Custom** (40 to 240 px, as before). Device setting `cellSize` is `"S"` or
  `"custom"`; a stored `"M"`, `"L"` or `"XL"` reads as `"S"`.
- Default sizes of tiles keep using the cell size setting (grid spec §3).

## 2. Pinned tile as icons

- The PINNED tile shows one icon per pinned tab, each in exactly one grid
  cell (1 × 1), filling the tile row by row in tab order. No header, no
  title text.
- Icon: a rounded square, inset 4 px inside its cell (square = cell minus
  8 px, centred), neutral translucent background, the site favicon centred
  (fallback: the globe icon). The active tab's icon has a small neutral dot
  below the favicon at bottom centre. A named pin without site access has a
  muted 4 px text-colour dot at the square's top-left, with no border. A pin
  from another window shows the board's `OTHER WINDOW` label on hover only.
- Hover: a pill tooltip with the pin's name (renamed name, else title) and
  ALLOW when the name lacks site access. Leaving starts a 150 ms hide grace;
  entering the tooltip cancels it so ALLOW stays reachable by mouse.
  A small × appears in the icon's top right corner to close the pin, clear
  of the corner resize handle.
- Click opens (same rules as rows today); drag moves the tab (same drop
  targets as today); F2 or the context of a focused icon renames (same rules
  as today). Icons are focusable buttons; arrow keys move focus.
- More pins than cells: the icon grid scrolls vertically inside the tile with
  the usual edge fade.
- Moving the tile: drag its empty space (icon insets, gaps, empty cells).
  Corner resize handles stay (corners win). Minimum size 1 × 1. Default size
  6 × 2.

## 3. Memory tile

- Firefox does not give add-ons per-tab memory (no API; webNavigation
  `processId` is unsupported; OS process names do not carry the site). The
  tile shows what can be measured, and says so in its empty state.
- **Header:** `MEMORY`, then Firefox's current total memory (all Firefox
  processes, macOS physical footprint, Linux PSS where readable else RSS),
  e.g. `3.4 GB`, a line `of 36 GB · system 71 % used`, and a sparkline of the
  last 5 minutes (one sample every 5 s while a Foxy page is visible).
- **Source:** the Foxy helper (the agent bridge host). The extension sends
  `{type: "memory", rid}` on the native port; the host measures the process
  tree under its parent (Firefox) and replies `{type: "memory", rid,
  firefox, processes, system: {total, used}}`. Without the helper (not
  installed, Windows, not connected) the header shows "Install the Foxy
  helper to see memory" with the install command in the README.
- **List:** loaded sites, scrollable: non-discarded `http(s)` tabs in normal
  windows grouped by host (without `www.`), sorted by loaded tab count, then
  most recently used. Row: favicon, host, `N tabs`. Hover shows `UNLOAD`,
  which discards every tab of that host except active tabs. The header shows
  the memory freed on its next samples.
- Synced setting `showMemory` (default on). Default size 5 × 6.

## 4. Ungrouped tabs rail and gear

- The rail's title is `UNGROUPED TABS`.
- The separate gear cell is removed. The rail runs to the bottom of the board;
  the gear is a round button inside the rail at its bottom right, and the tab
  list ends above it.
- The settings pane opens at top 0, right 0, 360 px wide, and ends one gap
  above the gear, so the gear stays visible and closes it.

## 5. Weather tile

- **Location:** `navigator.geolocation` (manifest permission `geolocation`,
  no prompt), coordinates rounded to 2 decimals before any request. Place name
  from BigDataCloud's free client reverse geocoder. Fallback and override: a
  device setting `weatherPlace` set from the pane by searching a city
  (Open-Meteo geocoding API); `auto` uses geolocation.
- **Data:** Open-Meteo forecast API (no key, CORS), `timezone=auto`: current
  temperature, apparent temperature, weather code, day/night, wind, humidity,
  precipitation; 24 hourly temperatures and codes with precipitation
  probability; 7 daily codes, min/max and sunrise/sunset.
- **Refresh:** on page load when the cached data is older than 15 minutes,
  then every 15 minutes while a Foxy page is visible. Cache in
  `storage.local` (shared by Foxy pages). Offline or failing: cached data with
  "Updated 2 h ago"; nothing cached: a short message and a retry button.
- **Units:** synced setting `tempUnit` `C` (default) or `F` (wind km/h or
  mph).
- **Design:** neutral glass card like other tiles; condition glyphs drawn as
  in-house inline SVG line icons in neutral grey, colour only as a small
  accent (sun core, rain dots). Layout follows the tile's pixel size with CSS
  container queries:
  - small (under ~150 px wide or ~100 px tall): glyph and temperature;
  - medium: glyph, large temperature, condition, place, high / low;
  - tall (from ~260 px): plus an hourly strip (scrolls sideways, edge fade);
  - taller (from ~460 px): plus 7 daily rows with a min/max range bar and a
    dot for the current temperature on today's bar.
- Synced setting `showWeather` (default on). Default size 5 × 5.
- Foxy now makes network requests for weather only (Open-Meteo, BigDataCloud);
  README Permissions and privacy lines say so.

## 6. Not included

- Per-tab or per-site memory figures (no Firefox API).
- Weather alerts, radar, multiple locations.
