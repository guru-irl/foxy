# Foxy base Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Move the add-on into `extension/`, rename it to Foxy (1.1.0), and switch the current page from Danfo/Bebas Neue to Google Sans Flex and Cascadia Mono.

**Architecture:** Pure file moves and renames, then a CSS font swap. No behaviour change on the page apart from fonts.

**Tech Stack:** Plain ES modules (no build step), node --test, Python 3 unittest, headless Firefox for previews.

**Spec:** `docs/superpowers/specs/2026-10-01-foxy-design.md` (§3 Repository, §4 Typography).

## Global Constraints

- No npm or pip installs, no new dependencies. Node's built-in test runner and Python's standard library only.
- Never write to `/tmp`, `$TMPDIR` or `/var/tmp`; scratch goes under the worktree's `.spider/scratch/`.
- Never read `~/.config/liquidfox-newtab/amo.env`, never run `scripts/sign.py` for real, never contact addons.mozilla.org, never push or create GitHub resources.
- Never modify anything outside the worktree (the Firefox profile included).
- Add-on ID stays `{4408f971-7930-41ea-9f93-b01231e40861}`; `strict_min_version` stays `140.0`.
- Console messages start with `Foxy:`.
- The signing credentials path stays `~/.config/liquidfox-newtab/amo.env` (do not rename it).
- Visual rules: no borders, outlines or drop shadows; neutral greys; colour only in small accents.
- Fixtures and docs contain no company-internal names; use generic titles.
- `npm test` must pass at the end of every task.

## Review Focus

1. A path still pointing at the old layout (root `src/`, `fonts/`, `manifest.json`) in a script, test or HTML file: every entry point (`npm test`, `scripts/build.py`, `scripts/preview.py`) must work from the repo root.
2. The xpi layout: `manifest.json` must sit at the root of the zip, not under `extension/`.
3. Font files missing from the zip, or a CSS `url()` that does not match a packaged file name exactly (case included).
4. Variable-font ranges: without `font-weight: 1 1000` / `font-stretch: 25% 151%` / `font-style: oblique 0deg 10deg` in `@font-face`, Firefox clamps or synthesizes instead of using the axes.
5. The group-title dot and the capitals no longer lining up after the font change.
