# Foxy grid board Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the kanban columns with a scrolling grid of square cells where every group, the pinned list, the saved list and the clock are movable, resizable tiles, keep TABS as a right rail, and add a settings pane (Foxy 3.0.0).

**Architecture:** A pure layout engine (`extension/src/grid/layout.js`) owns all geometry: columns, push-down placement, display fit, defaults. Small stores wrap `storage.sync` (tiles, synced settings) and `storage.local` (device settings). The page renders tiles with CSS Grid from a pure view function; pointer events move and resize tiles, HTML5 drag and drop still moves tabs.

**Tech Stack:** Firefox 157 MV3 WebExtension, plain ES modules, CSS Grid and container query units, `node --test`, headless Firefox browser tests (`scripts/browser_test.py`), Python smoke and preview scripts. No npm packages.

**Spec:** `docs/superpowers/specs/2026-10-03-foxy-grid-design.md` (and, for unchanged behaviour, `docs/superpowers/specs/2026-10-01-foxy-design.md`).

## Global Constraints

- No npm or pip installs; no new third-party code.
- Gap 16 px. Cell presets S 48, M 80, L 112, XL 144; custom 40 to 240 px. Default M.
- Minimum tile sizes: clock 3 × 2, others 2 × 2. Default targets: group, pinned, saved 288 × 384 px; clock 480 × 208 px; cells = `round((px + 16) / (cell + 16))`, clamped to the minimum.
- Rail: default 3 cells, minimum 2, maximum `max(2, floor(total / 2))`.
- Storage keys: `storage.sync` `tile:<id>` (`{x,y,w,h}`) and `settings`; `storage.local` `deviceSettings`.
- Tile ids: `group:<folderId>`, `pinned`, `saved`, `clock`.
- Visual rules: neutral black and grey, no borders, outlines or drop shadows, pill shapes, colour only as small accents, existing fonts (`Foxy Sans`, `Foxy Serif` clock, `Foxy Mono` URLs).
- Copy and docs: plain, neutral, concise; no em dashes.
- Commits as `Guru 🦄 <gurupungavn@gmail.com>` (repo config already set). Small commits per step group.
- Scratch only under the worktree's `.spider/scratch/`; never `/tmp`. Never touch the user's running Firefox or real profile. Never set `MOZ_DISABLE_CONTENT_SANDBOX`. Never push, build or sign.
- Gates for every task: `npm test`, `npm run test:browser`, `python3 scripts/smoke_firefox.py`, `python3 scripts/check_private.py`.

## Review Focus

1. Window narrowed or widened with tiles placed: display fit only, saved positions unchanged until that tile is moved (Task 1 `fit` tests, Task 5 browser test).
2. A layout change from another device arriving during a tile drag: held, applied after release or cancel (Task 5 test).
3. A new group created by dropping on empty cells before its folder mapping exists: tile shown at the drop rectangle, written once the mapping arrives (Task 4 test).
4. Corrupt or foreign values in `storage.sync` or `storage.local` (strings, negatives, fractions, huge numbers, wrong shapes): ignored, defaults used, no throw (Task 2 tests).
5. Long push chains and tiles wider than the column count on a narrow screen: no overlaps after `place` or `fit`, width capped (Task 1 tests).

### Task 1: Layout engine

**Files:**
- Create: `extension/src/grid/layout.js`
- Test: `test/grid-layout.test.js`

**Interfaces:**
- Produces (all pure; a Tile is `{ id: string, x: number, y: number, w: number, h: number }`, integers, cells):
  - `GAP = 16`, `CELL_PRESETS = { S: 48, M: 80, L: 112, XL: 144 }`
  - `kindOf(id: string): "group" | "pinned" | "saved" | "clock"`
  - `totalColumns(contentWidth: number, cell: number): number`

  - `place(tiles: Tile[], id: string, rect, cols: number): Tile[]` (new array, input untouched)
  - `fit(tiles: Tile[], cols: number): Tile[]`
  - `firstFree(tiles: Tile[], size: { w, h }, cols: number, fromY = 0): { x, y }`
  - `addMissing(tiles: Tile[], ids: string[], cols, cell): Tile[]` (places only ids not in `tiles`)
  - `arrange(ids: string[], cols, cell): Tile[]` (reset: `addMissing([], ids, ...)`)
  - `changedTiles(before: Tile[], after: Tile[]): Tile[]`

  - `railLimits(25)` → `{ min: 2, max: 12 }`; `railLimits(3)` → `{ min: 2, max: 2 }`.
  - `defaultSize("group", 80, 25)` → `{ w: 3, h: 4 }`; `("clock", 80, 25)` → `{ w: 5, h: 2 }`; `("group", 48, 25)` → `{ w: 5, h: 6 }`; `("clock", 144, 25)` → `{ w: 3, h: 2 }` (minimum); `("group", 80, 2)` → `w: 2`.

  - `arrange` with `["clock", "pinned", "group:a", "group:b", "saved"]` at cols 25, cell 80 → clock `{0,0,5,2}`, pinned `{5,0,3,4}`, then groups and saved left to right, no overlaps.
